
C 语言没有独立的 `string` 类型。C 字符串本质上是一个以 `'\0'` 结尾的 `char` 字符序列。

```c
char str[] = "abc";
```

等价于：

```c
char str[] = {'a', 'b', 'c', '\0'};
```

### 1. 字符串的两种常见写法

```c
char *s1 = "hello";
char s2[] = "hello";
```

区别：

| 写法                     | 本质        | 是否可修改 |
| ---------------------- | --------- | ----- |
| `char *s1 = "hello";`  | 指针指向字符串常量 | 不应修改  |
| `char s2[] = "hello";` | 字符数组      | 可以修改  |

例如：

```c
char s[] = "hello";
s[0] = 'H';

printf("%s\n", s);
```

输出：

```text
Hello
```

而：

```c
char *s = "hello";
s[0] = 'H';
```

可能产生未定义行为。

### 2. 单引号与双引号

```text
' ' → 一个字符
" " → 一个字符串
```

例如：

```c
char c = 'A';
char s[] = "A";
```

其中：

```text
'A'   → 一个字符
"A"   → 'A' '\0'
```

字符通常使用 `%c`：

```c
printf("%c\n", 'A');
```

字符串使用 `%s`：

```c
printf("%s\n", "Hello");
```

### 3. `'\0'` 是什么

`'\0'` 是空字符，也是 C 字符串的结束标志。

```c
char str[] = "Hello";
```

实际内容：

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

所以：

```c
char str[] = "abc";
```

虽然只有 3 个可见字符，但数组实际有 4 个元素：

```text
'a' 'b' 'c' '\0'
```

### 4. `'\0'` 和 `"\0"` 的区别

```c
'\0'
```

表示一个空字符。

```c
"\0"
```

表示一个字符串，实际包含：

```text
'\0' '\0'
```

第二个 `'\0'` 是编译器自动补上的字符串结束符。

### 5. 快速记忆

| 写法 | 含义 |
| --- | --- |
| `'A'` | 一个字符 |
| `"A"` | 一个字符串 |
| `'\n'` | 一个换行字符 |
| `"\n"` | 包含换行字符的字符串 |
| `'\0'` | 字符串结束符 |
| `"abc"` | `'a' 'b' 'c' '\0'` |

```text
' '  → character → 单个字符
" "  → string    → 字符串

C 字符串 = char 字符序列 + '\0'
```
