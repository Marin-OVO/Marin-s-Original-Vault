# Lecture 1
**信号X本质上是一种函数, X(t) / X(n)**
**X(n): 离散时间信号DT**
**X(t): 连续时间信号CT(模拟信号)**
## 1. 离散时间信号
n为整数
任意一个离散时间信号DT都可以用一系列冲激信号的线性组合组成
### 离散时间冲激信号(Kronecker delta):
Delta(n) = 1 if n = 0 else 0
### 离散时间单位阶跃信号:
U(n) = 1 if n >=0 else 0
U(n) = Delta(n) + Delta(n - 1) + Delta(n - 2) ...
U(n) = $\sum$ Delta(n - k) k $\in$ (0, $\infty$)
U(n) = $\sum$ Delta(l) l = n - k, l $\in$ (-$\infty$, n)
Delta(n) = (U(n) - U(n - 1) ) / 1
冲激信号和单位阶跃信号相互转换？

X(n) = $\sum$ X(n)Delta(n - k) k $\in$ (-$\infty$, $\infty$)
