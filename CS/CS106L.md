# Lecture 1 流

**C++中的string实际上是字符数组**

```C
// 字符串常量
char *s1 = "hello";

// 字符数组
char s2[] = "hello";
```

```C++
// 缓冲区
// IO 流 输入输出流
// Output
/* 1. 位置指针在stream头部 */
ostringstream oss("Ito-En Green Tea");
cout << oss.str << endl; // Ito-En Green Tea

oss << "16.9 Ounces";
cout << oss.str << endl; // 16.9 Ouncesn Tea

/* 2. 位置指针定义在stream末尾 */
ostringstream oss("Ito-En Green Tea", ostringstream::ate);
cout << oss.str << endl; // Ito-En Green Tea

oss << "16.9 Ounces";
cout << oss.str << endl; // Ito-En Green Tea16.9 Ounces

// Input
istringstream iss("16.9 Ounces");

double amount;
string unit;

iss >> amount;
iss >> unit;

// IO 格式
oss << var1 << var2 
iss >> var1 >> var2

```
