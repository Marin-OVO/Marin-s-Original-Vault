# Lecture 4 控制台程序、向量与网格

## 一 向量

C++向量只能存储一种类型 相当于Python中的`list()`和Java中的`ArrayList`, 需要导入`<vector.h>`

```C++
Vector<int> vec;

vec.add(4);
vec.add(8);

vec.insert(0, 8); // 插入value
vec.sort();       // 排序

Vector<int> vec = {4, 8};

cout << vec[0] << endl;

vec.remove(0);

cout << vec.size() << endl;
```
